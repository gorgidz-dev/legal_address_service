# Дизайн-система uradres.net

Снято с кода 21.08.2026 (коммит `f9c2ecf`). Источник правды — `frontend/src/design/*.css`
и `frontend/src/styles.css`, а не спека: спека [2026-05-11-catalog-design-system-design.md](superpowers/specs/2026-05-11-catalog-design-system-design.md)
описывает замысел, код с тех пор ушёл вперёд. Расхождения собраны в разделе 11.

Тема одна — светлая. Тёмной нет и не планировалась.

## 1. Где что лежит

Порядок импорта задан в `frontend/src/main.tsx` и имеет значение: слой кабинета идёт
последним, потому что пересечений с остальными не имеет и ничего не перебивает.

без внешних CDN, это осознанное решение ради скорости в РФ и дружелюбия к CSP.

## 2. Два поколения токенов

- **`--ds-*`** — актуальная система (indigo). Её используют каталог, лендинг, оболочка
  **и кабинет**. Это 1317 обращений против 284 у legacy.
- **`--lg-*`** — только `styles.css`. Технический долг, а не отдельный язык.

Важно: шапка `legacy-tokens.css` описывает эстетику как «тёплый оливковый B2B», но
`--lg-accent` там уже `#5b5bd6` — тот же самый `--ds-indigo-500`. Оливковое наследие
осталось точечно: фон страницы `--lg-bg-page: #f5f6f3`, граница `--lg-border: #dfe3dc`
и зелёный фокус инпутов `#609372` в `styles.css:1433`. Комментарий стоит считать
устаревшим, а не описанием текущего вида.

## 3. Цвет

**Indigo — бренд: CTA, ссылки, фокус, акценты.**

```

100 #dde0fa   400 #7d83e0   700 #3b38a3   950 #0b0a2e
200 #bcc1f5   500 #5b5bd6   800 #2b2980
```

**Slate — нейтрали: текст, фон, границы.**


Отдельный `--ds-border-soft: #ececff` — граница карточек, мягче Slate-100 и холоднее её.

**Семантические пары** (всегда bg + fg, без промежуточных оттенков):

| Роль | Фон | Текст |
|---|---|---|
| success | `#dcfce7` | `#166534` |
| warning | `#fef3c7` | `#92400e` |
| danger | `#fee2e2` | `#991b1b` |
| info | `#dbeafe` | `#1e40af` |
| neutral | `#f1f3f6` | `#475569` |
| brand | `#f0f1fd` | `#3b38a3` |

**Как применяется на практике:**

- Фон страницы — `#fafbfc`, поверхности — чистый `#fff`.
- Основной текст — `--ds-indigo-950` (`#0b0a2e`), не чёрный и не Slate-900.
- Приглушённый текст — `--ds-slate-500`.
- Первичная кнопка — заливка `indigo-500`; **активный чип — заливка `indigo-950`**,
  не брендовым индиго: выбранный фильтр темнее кнопки, иначе они спорят за внимание.

## 4. Типографика

Inter для всего, JetBrains Mono — для номеров и идентификаторов.

| Токен | Десктоп | ≤640px |
|---|---:|---:|
| `display-xl` | 48px | 30px |
| `display-lg` | 36px | 26px |
| `display-md` | 28px | 22px |
| `heading-lg` | 22px | — |
| `heading-md` | 18px | — |
| `heading-sm` | 15px | — |
| `body-md` | 14px | — |
| `body-sm` | 13px | — |
| `label` | 11px | — |
| `mono` | 12px | — |

Ужимаются только три display-размера — текстовые уровни на мобильном те же.

Межбуквенное: `tightest -0.04em` (hero h1), `tighter -0.03em`, `tight -0.02em`,
`snug -0.015em`, `wide +0.06em` (мелкие заглавные подписи). Правило простое: чем
крупнее кегль, тем плотнее трекинг; `wide` — только для `label`-уровня в верхнем регистре.

## 5. Ритм, форма, движение

**Отступы**, база 4px: `1:4 · 2:8 · 3:12 · 4:16 · 6:24 · 8:32 · 12:48 · 16:64 · 20:80`.
Шкала намеренно с пропусками (нет 5, 7, 9…) — меньше выбора, ровнее ритм.

**Радиусы**: `sm 4 · md 8 · lg 10 · xl 14 · pill 9999`.
Кнопки — всегда `md`; `pill` зарезервирован за чипами и бейджами. Это осознанная
правка: раньше на стыке каталога и кабинета читались два разных языка форм.

**Тени** — четыре ступени, все с индиго-подмесом `rgba(11,10,46,…)`, не серые:

```
sm  0 1px 0 / 0.04                          — карточка в покое
md  0 1px 3px / 0.06 + 0 1px 2px / 0.04     — приподнятая поверхность
lg  0 4px 12px / 0.08 + 0 2px 4px / 0.04    — hover карточки, поповеры
xl  0 18px 40px / 0.10 + 0 6px 12px / 0.06  — модалки
```

**Движение**: `fast 120ms` (цвет, границы), `base 200ms` (трансформации карточек),
`slow 320ms`. Основная кривая — `cubic-bezier(0.2, 0.8, 0.2, 1)`, для мелочи `ease-out`.
При `prefers-reduced-motion: reduce` все три длительности обнуляются на уровне токенов,
поэтому отключать анимации в компонентах не нужно.

## 6. Раскладка

- `--ds-page-max-width: 1440px` — под сетку карточек: на широком экране встаёт
  четвёртая колонка.
- `--ds-prose-max-width: 1180px` — сплошной текст (FAQ, «Для собственников», шаги,
  футер) уже сетки, иначе строка уезжает за комфортные ~90 знаков.
- `--ds-page-pad-x`: 32px, на ≤640px — 16px.
- Сетка каталога: `repeat(4, 1fr)`, gap 18px.
- `.ds-hero__h1` ограничен 640px — на 1440 заголовок иначе заходил под фото.

## 7. Примитивы

**Кнопка `.ds-btn`** — `inline-flex`, gap 8px, вес 600, радиус 8px, переход 120ms.

| Размер | Кегль | Паддинги |
|---|---:|---|
| `--sm` | 12px | 6/12 |
| `--md` | 13px | 9/16 |
| `--lg` | 14px | 12/22 |

Варианты: `--primary` (заливка `indigo-500`, белый текст), `--secondary` (белая,
граница `slate-200`, текст `indigo-950`), `--ghost` (прозрачная, текст `indigo-500`),
плюс `--danger` и `--icon`.

**Чип `.ds-chip`** — pill, 6/12, 12px/500, белый с границей `slate-200`;
активный (`--active`) заливается `indigo-950`. Есть `__x` для сброса.

**Бейдж `.ds-badge`** — pill, 3/9, 11px/600, `UPPERCASE`, трекинг 0.04em, `nowrap`.
Цвет задаётся семантической парой из раздела 3. Модификатор `--new` и точка `__dot`.

**Поле `.ds-input`** — радиус 10px, паддинг 10/12, граница `slate-200`, `min-width: 220px`.
Внутренний `input` без собственной рамки; фокус — граница `indigo-500` + кольцо
`0 0 0 3px rgba(91,91,214,0.15)`. Ошибка — `--error` плюс `.ds-input-error-text`.

**Карточка `.ds-card`** — белая, граница `--ds-border-soft`, радиус 10px, тень `sm`,
`overflow: hidden`; на hover меняются трансформация, тень и цвет границы за 200ms.
Подэлементы: `__media` (с фолбэком из инициалов и счётчиком фото), `__body`, `__title`,
`__sub`, `__price-block`, `__options`, `__compare`.

**Статистика `.ds-stat`** — `__num` 28px/700 с плотным трекингом и `line-height: 1`,
под ним `__lbl` 11px `UPPERCASE` в `slate-500` с трекингом `wide`.

**Иконка `.ds-iconbox`** — квадрат с радиусом 8px и градиентом
`linear-gradient(135deg, indigo-500, #8b87ff)`, размеры `--sm/--md/--lg`.
Единственный градиент в системе — больше нигде заливок с переходом нет.

**Ссылка `.ds-lnk`** — `indigo-500`, вес 500, подчёркивание через нижнюю границу,
которая появляется на hover.

## 8. Семейства классов

- `.ds-*` — публичная часть: каталог, лендинг, карточка адреса, юр. страницы, отзывы.
- `.cab-*` — личный кабинет: `cab-shell`, `cab-sidebar`, `cab-table`, `cab-timeline`,
  `cab-stat`, `cab-badge`, `cab-sla`, `cab-fill` и т. д. Живёт на тех же `--ds-*` токенах,
  но со своими компонентами — это не копия публичных примитивов.
- Без префикса (`.btn`, `.field`, `.modal-panel`, `.registry-table`) — legacy-слой
  в `app-shell.css` и `styles.css`.

## 9. Брейкпоинты

Токенов для них нет, значения проставлены по месту. Фактический инвентарь — 15 разных
границ; рабочими можно считать три:

| Граница | Вхождений | Смысл |
|---|---:|---|
| `max-width: 640px` | 7 | мобильный: паддинги, display-шкала, одна колонка |
| `max-width: 900px` | 5 | планшет |
| `max-width: 760px` | 5 | планшет (дубль 900 по смыслу) |

Остальные (`1280`, `1023`, `768`, `700`, `600`, `901–1199`…) — единичные, под конкретные
секции. Это самая заметная нестройность системы, см. раздел 11.

## 10. Доступность

- `.sr-only` есть и используется для текста, доступного только скринридеру.
- `prefers-reduced-motion` обрабатывается централизованно, на уровне токенов.
- Поля ввода везде получают видимый фокус: `outline: none` встречается 8 раз, и
  **каждое** — в паре с заменой: границей `indigo-500` и кольцом
  `0 0 0 3px rgba(91,91,214,0.15)`. Глобального сброса фокуса нет.
  Само кольцо при этом захардкожено 6 раз подряд — токена под него не завели.
- Кнопки, ссылки, чипы и карточки-кнопки полагаются на браузерное кольцо по умолчанию:
  явное `:focus-visible` во всей системе одно (`app-shell.css:812`), в `cabinet.css`
  слово `focus` не встречается ни разу. Отдельного токена фокус-кольца для `--ds-*` нет
  (у legacy он был: `--lg-focus-ring`).

## 11. Расхождения и находки

Собрано при сверке кода со спекой — это список наблюдений, а не задач.

1. **Спека описывает замысел, не результат.** `--ds-page-max-width` в спеке — 1180px,
   в коде 1440px, а 1180 переехал в отдельный `--ds-prose-max-width`. Такие правки
   в коде прокомментированы, но в спеку не вернулись.
2. **Комментарий `legacy-tokens.css` устарел** — «тёплый оливковый» при `--lg-accent`,
   равном indigo. Читающий получит неверное представление о системе.
3. **Разнобой брейкпоинтов**: 15 значений, из них `760` и `900` делят одну роль.
   Токенов нет, поэтому расхождение ничем не ловится.
4. **Фокус у неинпутов** не оформлен (раздел 10) — единственная содержательная
   a11y-дыра, которую видно из CSS. Заодно кольцо фокуса инпутов продублировано
   шесть раз буквальным `rgba(91,91,214,0.15)` вместо токена.
5. **`app-shell.css` шире своего имени** — по плану миграции там должна быть оболочка,
   фактически лежат ещё модалки, карточка адреса в каталоге, «Чаты», «Услуги адресов»
   и редактор адреса собственника. Это зафиксировано комментарием в `main.tsx`.
6. **`framer-motion`** (зависимость ^12.38.0) подключён ровно в одном файле —
   `publicCatalog.tsx`. Остальная анимация — на CSS-переходах.
7. **`styles.css`, 1911 строк, всё ещё на `--lg-*`** — последний непереехавший слой.
   Кабинет мигрировал на `--ds-*`, дашборды нет.
