# Claude Design — промпты и инструкция (мобильное приложение uradres.net)

Каркас мобильного приложения генерим в Claude Design вместо Stitch.
Три промпта ниже вставляются по очереди, каждый — готовым куском.

## Как работать

**Вариант А — в этой же сессии Claude Code.** Просто сказать: «собери
дизайн-канвас по промпту 1». У Claude Code есть тот же движок (skill
`design`): он публикует канвас как Artifact с редактором Claude Design —
артборды, клик-выделение, панель свойств, экспорт PNG/PDF.

**Вариант Б — в приложении Claude / claude.ai.** Новый чат → вставить
промпт 1 → приложить к сообщению файлы (важно, это стилевой якорь):

- `frontend/public/logo.svg` — логотип;
- скриншоты `01-hero.png`, `03-cards.png`, `07-about-requisites.png`
  (лежат в передаче из сессии от 21.08.2026).

Правила, которые экономят часы:

1. **Не проси все экраны разом.** Промпт 1 → смотришь → правки → промпт 2.
   Стиль между партиями держится, если следующий промпт начинается со слов
   «в том же стиле и на тот же канвас».
2. **Правки — точечные и словами про элемент**, а не «сделай красивее»:
   «на экране Каталог подними цену над кнопкой», «бейдж статуса сделай
   меньше». В редакторе канваса мелочи можно двигать руками.
3. **Тексты не давать переводить.** Если в макете появился английский или
   выдуманная строка — сказать: «верни точные русские строки из промпта».
4. Экспорт: PNG на экран — эти PNG потом пойдут мне как спецификация
   для кода.

## Промпт 1 — дизайн-система + публичная часть (4 экрана)

```
Сделай дизайн-канвас мобильного приложения (артборды 390×844, iOS-стиль)
для uradres.net — российского B2B-маркетплейса юридических адресов для
регистрации компаний. Весь интерфейс на русском, строки использовать ровно
как написано ниже, ничего не переводить и не сочинять.

ДИЗАЙН-СИСТЕМА (строго):
- Светлая тема, premium B2B, сдержанный минимализм уровня Linear.
- Фон экрана #fafbfc, карточки и поверхности #ffffff, граница карточек #ececff.
- Основной текст #0b0a2e (тёмный индиго, не чёрный), вторичный #64748b.
- Акцент один: индиго #5b5bd6, нажатое состояние #4a47c2.
- Шрифт Inter; номера и суммы можно JetBrains Mono.
- Радиусы: кнопки 8px, карточки и поля 10px, модалки 14px, чипы и бейджи —
  полностью круглые (pill).
- Primary-кнопка: заливка #5b5bd6, белый текст, высота 44px, вес 600.
  Secondary: белая с границей #e2e6ec. Ghost: без заливки, текст индиго.
- Выбранный чип фильтра заливается #0b0a2e с белым текстом (тёмный, НЕ индиго).
- Поля ввода: белые, граница #e2e6ec, фокус — граница #5b5bd6 + мягкое
  индиго-свечение.
- Отступы кратны 4px, боковой паддинг экрана 16px. Тени едва заметные,
  с холодным индиго-подтоном, никогда серые и тяжёлые.
- Единственный допустимый градиент — плитка-заглушка вместо фото:
  135°, #5b5bd6 → #8b87ff, поверх — инициалы улицы белым.
- Без тёмной темы, без иллюстраций, без эмодзи. Иконки в стиле lucide,
  контурные, штрих 1.5–2px.

ЭКРАН 1 «Каталог» (главный, до входа):
- Топбар: логотип «uradres.net», справа ghost-кнопка «Войти».
- Заголовок: «Маркетплейс юридических адресов.» и второй строкой индиго:
  «За 1 день.»
- Подзаголовок: «Проверенные собственники, готовый комплект документов
  с гарантийным письмом и выпиской ЕГРН.»
- Три строки-обещания с контурными иконками: «Возврат средств при отказе
  налоговой», «Замена адреса без доплат», «Документы соответствуют
  требованиям ФНС».
- Статистика 2×2 (крупная цифра, под ней подпись 11px ЗАГЛАВНЫМИ серым):
  «26 / АДРЕСОВ В КАТАЛОГЕ», «10 / ИФНС В КАТАЛОГЕ», «10 / ГОРОДОВ»,
  «6 и 11 / МЕСЯЦЕВ АРЕНДЫ».
- Поиск «По адресу или ИФНС», под ним чипы: «Дешевле 20 000 ₽»,
  «Дешевле 30 000 ₽», «С почтой» (первый чип — в выбранном состоянии,
  залит #0b0a2e). Счётчик «Найдено 26 адресов».
- Две карточки адреса (одна колонка): фото сверху; заголовок
  «г. Москва, ул. Академика Королёва, д. 13, стр. 1»; подстрока
  «офис 214 · ИФНС № 46»; переключатель срока «11 мес. | 6 мес.»;
  чекбокс «+ почта 4 000 ₽/мес»; цена «28 000 ₽» крупно индиго, под ней
  «за 11 мес.»; кнопка primary «Оформить заявку». Вторая карточка —
  с плиткой-заглушкой (градиент + инициалы «АК») вместо фото, адрес
  «г. Екатеринбург, ул. Малышева, д. 51», «офис 1704 · ИФНС № 39»,
  цена «24 000 ₽».

ЭКРАН 2 «Карточка адреса»:
- Фотогалерея с точками-индикаторами, бейдж «+1 фото».
- Заголовок-адрес «г. Москва, ул. Академика Королёва, д. 13, стр. 1»,
  мета-строки: «ИФНС № 46», «офис 214», рейтинг «★ 4.8 · 12 отзывов».
- Блок цен: «6 месяцев — 18 000 ₽», «11 месяцев — 28 000 ₽»
  (11 выделено).
- Список «Входит в стоимость» с галочками: «Гарантийное письмо»,
  «Выписка ЕГРН», «Договор аренды», «Почтовое обслуживание — 4 000 ₽/мес»
  (последний — как доп. услуга-тег).
- Превью карты. Секция отзывов: один отзыв (автор, дата, ★★★★★, текст).
- Прилипшая к низу primary-кнопка «Оформить заявку».

ЭКРАН 3 «Заявка»:
- Заголовок «Оформление заявки», под ним карточка-сводка адреса.
- Поля: «Название компании», «Контактное лицо», «Телефон», «E-mail».
- Сегмент «Срок аренды: 6 мес. | 11 мес.» (11 выбрано).
- Радио: «Регистрация новой компании» (выбрано) / «Смена адреса
  действующей».
- Чекбокс со ссылкой: «Согласен на обработку персональных данных».
- Primary-кнопка «Отправить заявку».

ЭКРАН 4 «Вход»:
- Логотип по центру, поля «E-mail» и «Пароль», primary «Войти»,
  ghost «Зарегистрироваться», ссылка «Забыли пароль?».
- Внизу мелко: «ООО «Юрадрес.Нет» · ИНН 7751397240».
```

## Промпт 2 — кабинет клиента (4 экрана)

```
Продолжай на том же канвасе, в той же дизайн-системе (светлая, индиго
#5b5bd6, фон #fafbfc, карточки #fff с границей #ececff, Inter, радиусы
8/10, статус-бейджи pill). Добавь 4 артборда 390×844 — кабинет клиента
после входа. У всех экранов кабинета внизу таб-бар из трёх вкладок:
«Заявки» (иконка папки, активна на экране 1), «Календарь» (календарь),
«Чаты» (сообщение, с индиго-точкой непрочитанного). Сверху — заголовок
экрана слева и круглый аватар справа.

Статус-бейджи: pill, текст 11px ЗАГЛАВНЫМИ, пары фон/текст:
- success #dcfce7/#166534 — «Оплачена», «Активна», «Готова к выдаче»,
  «Завершена»
- brand #f0f1fd/#3b38a3 — «Ожидает оплату»
- info #dbeafe/#1e40af — «Проверка администратора», «Готовятся документы»
- warning #fef3c7/#92400e — «Нужны уточнения», «Передана собственнику»,
  «Истекла»
- danger #fee2e2/#991b1b — «Спор», «Отклонена собственником»
- neutral #f1f3f6/#475569 — «Черновик», «Отменена»

ЭКРАН 5 «Заявки» (вкладка по умолчанию):
- Заголовок «Заявки», подпись «Всего заявок: 3».
- Три карточки заявки: адрес одной строкой, название компании серым,
  статус-бейдж, дата «21.08.2026», цена «28 000 ₽».
  Статусы у трёх карточек: «Ожидает оплату» (brand), «Готовятся документы»
  (info), «Активна» (success).

ЭКРАН 6 «Заявка — детально»:
- Крошки «← Заявки», заголовок-адрес, бейдж «Ожидает оплату».
- Вертикальный таймлайн статусов (точки и линия): пройденные — индиго
  с датами («Заявка создана · 18.08», «Принята собственником · 19.08»),
  текущий — «Ожидает оплату» выделен, будущие — серые
  («Подготовка документов», «Готова к выдаче»).
- Блок оплаты: сумма «28 000 ₽», primary-кнопка «Оплатить».
- Список документов: строки с иконкой файла, «Гарантийное письмо.pdf ·
  240 КБ», «Договор аренды.docx · 96 КБ», иконка скачивания.
- Secondary-кнопка «Чат по заявке».

ЭКРАН 7 «Календарь»:
- Заголовок «Календарь». Месячная сетка августа 2026, две даты отмечены
  индиго-точками.
- Под сеткой список событий: «21 авг · г. Москва, ул. Академика
  Королёва — Окончание аренды» с бейджем «Скоро» (warning);
  «03 сен · г. Екатеринбург, ул. Малышева — Продление договора»
  с бейджем «Просрочено» (danger).

ЭКРАН 8 «Чат»:
- Заголовок «Чаты», под ним список: две строки — адрес, превью последнего
  сообщения серым, время, у первой — индиго-pill «2» непрочитанных.
- Ниже (или отдельной областью) открытый диалог: сообщения собеседника
  слева на фоне #f1f3f6 с подписью «Собственник» 11px, свои справа на
  #f0f1fd; время 11px серым. Строка вложения: иконка скрепки,
  «Гарантийное письмо.pdf · 240 КБ».
- Композер внизу: поле «Сообщение…», скрепка, круглая индиго-кнопка
  отправки.
```

## Промпт 3 — доводка (примеры формулировок)

```
— На экране «Каталог» цена и кнопка «Оформить заявку» в одной строке:
  цена слева, кнопка справа.
— Статус-бейджи на экране «Заявки» перенеси в правый верхний угол карточек.
— В таймлайне на экране «Заявка — детально» сделай текущий шаг жирным
  с индиго-точкой крупнее остальных.
— Верни точные русские строки из промпта, ничего не переводи.
— Плитку-заглушку фото сделай квадратной 96×96 в списке, полной ширины —
  только в карточке адреса.
```

## Что дальше

Утверждённые экраны экспортировать в PNG и вернуть в Claude Code —
они станут спецификацией для кода. Код пишется по docs/mobile-api.md:
бэкенд уже отдаёт bearer-авторизацию (`POST /mobile/auth/login`),
каталог публичный, кабинетные эндпоинты принимают Bearer-токен.
