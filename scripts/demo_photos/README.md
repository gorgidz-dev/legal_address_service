# Фотографии для витринного набора

Используются скриптом `scripts/seed_demo_providers.py` как снимки помещений у
демонстрационных карточек каталога.

## Происхождение и лицензия

Все файлы — со стока **Pexels** (https://www.pexels.com). Имя файла содержит id
исходной публикации: `px-<id>.jpg` → `https://www.pexels.com/photo/<id>/`.

Pexels License разрешает бесплатное использование, в том числе коммерческое, без
указания авторства и без письменного разрешения. Изображения уменьшены до 1600 px
по длинной стороне и пережаты в JPEG.

## Чего здесь намеренно нет

- кадров с узнаваемыми людьми — чтобы не требовалось согласие на использование
  изображения гражданина (ст. 152.1 ГК РФ);
- узнаваемых зданий, привязанных к конкретному городу России, — снимки
  нейтральные, чтобы не выдавать чужой объект за сдаваемое помещение.

## Важно

Это заглушки. По мере подключения реальных собственников карточки замещаются
их собственными фотографиями, а весь набор снимается командой:

```
python -m scripts.seed_demo_providers --purge
```
